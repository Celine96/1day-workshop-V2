# 2.4 [실습] 미니 KPI 대시보드 만들기

---

> **오늘의 흐름:** ① 샘플 데이터로 직접 만들어 보기 → ② 진짜 KAI 레포트와 비교 → ③ 어디가 다른지 발견하고 개선하기.
> KAI 레포트를 처음부터 똑같이 만들지 않아도 괜찮아요. **"내 손으로 데이터 → HTML 대시보드를 만든 경험"**이 오늘의 진짜 결과물입니다.

---

### [준비] 실습 파일 확인

1.2에서 압축 해제한 `태이님` 폴더 안에 `ig_kpi_sample.csv`가 들어있어요. 이 파일에는 14일치 IG 일별 지표가 두 계정 분량으로 들어 있어요(총 28행).

| 컬럼 | 설명 | 예시 |
|---|---|---|
| `date` | 날짜 | 2026-04-21 |
| `account` | IG 계정 | rexa_official_kr |
| `reach` | 도달 수 (그날 게시물을 본 사람 수) | 87 |
| `profile_visits` | 프로필 방문 수 | 4 |
| `new_follows` | 신규 팔로우 수 | 2 |
| `dms_received` | 수신 DM 수 | 0 |
| `hot_dms` | HOT DM (상담/문의 키워드 포함) 수 | 0 |

> 샘플 CSV가 없다면 [여기서 다운로드](/ig_kpi_sample.csv)할 수 있어요.

---

### [실습] 대시보드 생성 프롬프트

클로드 코드에 아래 프롬프트를 입력해 주세요. 모드는 `plan mode on` 또는 `auto mode on`을 권장합니다.

[클로드 코드에 입력]
```
"이 폴더의 ig_kpi_sample.csv를 읽고,
KAI가 만든 rexa.html 같은 KPI 추적 HTML 대시보드를 만들어줘.

데이터 가공:
- 두 계정(rexa_official_kr, 30sec.budongsan)을 합산한 주간 합계 계산
- 참여율 = (profile_visits + new_follows) / reach × 100
- HOT DM과 일반 DM 분리해서 표시

포함할 것:
- 페이지 상단: 보고서 제목 + 기간 표시 (CSV에서 자동으로 추출)
- KPI 카드 4개 (목표 vs 현재):
  · 주간 도달 (목표 ≥ 500명/주)
  · 참여율 (목표 ≥ 5%)
  · 수신 DM (목표 ≥ 2건/주)
  · HOT DM (목표 ≥ 1건/주)
- 일별 도달 추이 라인 차트 (계정별 색상 구분)
- 계정별 상세 표 (날짜·도달·방문·팔로우·DM)

디자인:
- 색상: Deep Navy (#0F172A) 배경 강조 + Orange (#F97316) 액센트
- 한글 폰트는 Pretendard 우선
- 단일 HTML 파일 (CSS 임베드, 외부 의존성 최소)
- 결과물: output/dashboard.html"
```

클로드가 작업을 시작하면:
- CSV를 먼저 읽고 행 수와 기간을 확인하는지
- 차트 라이브러리를 어떻게 처리하는지 (인라인 SVG vs CDN)
- KPI 계산 로직을 코드 주석으로 남기는지

관찰해 보세요. 막히면 `think hard`를 붙여서 다시 요청해도 좋아요.

### [실습] 결과물 확인

완료되면 `태이님/output/dashboard.html` 파일이 생성돼요. 두 가지 방법으로 열 수 있어요:

Step 1. 파일 탐색기에서 직접 열기
- `태이님/output/dashboard.html`을 더블클릭 → 기본 브라우저에서 자동으로 열려요.

Step 2. 클로드 코드에 부탁하기

[클로드 코드에 입력]
```
"방금 만든 output/dashboard.html을 브라우저에서 열어줘"
```
