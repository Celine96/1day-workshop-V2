# 2.3 파이프라인 흐름

---

### [개념] 4단계로 보는 KAI의 작업 흐름

```
[1. 수집]                [2. 가공]                [3. 시각화]            [4. 발행]
Instagram               퍼널 전환율              HTML 대시보드          GitHub Pages
Insights API     →      계산              →      생성             →    자동 배포
```

| 단계 | 담당 | 핵심 동작 |
|:--|:--|:--|
| 1. 수집 | Instagram Insights API | 출입증(API 키)으로 창구에 접속해 도달/방문/팔로우/DM 데이터를 받아옴 |
| 2. 가공 | KAI | 퍼널 전환율 계산. 목표값과 비교해서 ✅ 달성 / ❌ 미달 판정 |
| 3. 시각화 | KAI | HTML 템플릿에 숫자를 채워 KPI 카드·추이 그래프·DM 후보 표를 만듦 |
| 4. 발행 | 자동 배포 워크플로 | 완성된 HTML을 GitHub Pages로 업로드 → 공개 URL이 갱신 |

---

### 실무 포인트

> 이 파이프라인은 **매주 자동으로 한 번 실행**돼요. 사람이 손대지 않아도 매주 새 레포트가 같은 URL에서 갱신됩니다.
>
> 마케팅 회의 때 "이번 주 어떻게 됐죠?" 한 마디로 끝나요.
